# Domain documentation

This repository has a single domain context: Finnish imbalance-price forecasting.
Use README section 12 as the existing vocabulary and README sections 3-5 for
timing, data availability, and schema definitions.

When present, read the root `GLOSSARY.md` and relevant decisions in `docs/adr/`
before exploring the affected area. Create these lazily as new terms or
significant design decisions are resolved; their absence does not block work.

Use glossary terms consistently in conversation, plans, reports, and code. Keep
definitions in the glossary and implementation trade-offs in decision records.
Use the formats supplied with the `domain-modeling` skill. Surface a conflict
with an existing decision explicitly before proposing a different approach.
